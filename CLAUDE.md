# Repository guidelines

## Commit messages are public

This repository is published publicly (aws-samples). Commit messages are part of
the permanent, public git history. Always write them for a public audience:

- Describe **what changed and why** in neutral, professional language.
- Do **not** reference internal-only tools, systems, processes, ticket IDs,
  URLs, team names, or reviewers.
- Do **not** include secrets, credentials, customer names, or any confidential
  or personally identifiable information.
- Avoid internal shorthand or jargon that would not make sense to an external
  reader.

Apply the same standard to code comments, documentation, and any other content
committed to this repository.
